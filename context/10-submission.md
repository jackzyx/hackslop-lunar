# Submission checklist

Portal: https://www.spaceappschallenge.org (project submission opens **Sat 09:00**,
closes **Sun 23:59 local**). Our target: **submitted by Sun 10:00**, before the finals.
Only submitted teams get NASA certificates. Global judging needs only the project page
and the video: assume nobody runs the code.

The 2026 Project Submission Guide was due 13 Nov and the site was returning 503 when
this was written. **Re-read it Friday** and fix anything below that differs:
https://www.spaceappschallenge.org/resources/project-submission-guide/

## Team admin
- [ ] Every member registered and **confirmed** (not waitlisted) for the Athlone Local Event.
- [ ] Team created on the portal, Challenge 11 selected, all members joined (max 6).
- [ ] **Sun 06:00: one member confirms team status at the Atrium X support desk.**
- [ ] Sun 07:00: draft presentation submitted for the 08:00 mentor dry run.

## Project page (create Sat 09:00, polish Sun 04:00-06:00)
- [ ] Title and one-line summary ("Long Shadow: ...").
- [ ] High-level summary: problem, what we built, how it works, why it matters.
- [ ] **Link to the 30 s demo video** (YouTube/Vimeo/Drive, public or unlisted, export at 29 s).
- [ ] **Link to the final project**: deployed app URL + public GitHub repo (with LICENSE).
- [ ] Optional: link to the 7 slides (PDF).
- [ ] Use of NASA data: name each product (LOLA PGDA 90/69/78, NAIF SPICE DE440, JPL Horizons) with links.
- [ ] Space agency partner data, if any.
- [ ] References: every dataset, library, image, font, music track (from `references.md`).
- [ ] **Use of AI**: which tools, for what (code, text, images); no AI imagery unless watermarked.
- [ ] Tags/keywords.

## Repo (public, open source)
- [ ] LICENSE file (MIT unless the team decides otherwise).
- [ ] README: what it is, live link, how to run offline, how to rebuild data, validation numbers, limits, data attribution, AI disclosure.
- [ ] **Remove `context/` (internal strategy) before making the repo public**, or move the public-safe parts to `docs/`.
- [ ] No secrets, no large data files (data/ is gitignored).

## Video
- [ ] <= 30 s (export 29 s). Works with sound off; English subtitles burned in.
- [ ] Opens on the light, not a logo.
- [ ] Music (if any) free to use and cited.

## Live final (Sun from 11:30)
- [ ] Laptop charged, app running **offline**, video stored locally.
- [ ] Laptop to projector tested (HDMI/USB-C adapters), 60 s setup drill done twice.
- [ ] Assume we present first.
